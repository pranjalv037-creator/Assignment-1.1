Assignment 1.1 — How a Website Works


Aim


To understand how a website works when a user enters a URL in a web browser.


Answer


When a user types a URL (Uniform Resource Locator) into a web browser, such as Google Chrome, the browser acts as a client and sends a request to the appropriate web server through the internet. First, the Domain Name System (DNS) converts the domain name into an IP address to locate the server. The browser then sends an HTTP (Hypertext Transfer Protocol) or HTTPS (Hypertext Transfer Protocol Secure) request to the server. HTTP is used for communication between the client and server, whereas HTTPS provides secure, encrypted communication. The server processes the request and, if required, communicates with a database to retrieve or store information. The database stores and manages data, while the server sends an HTTP response containing the requested resources, such as HTML, CSS, JavaScript, and images. The browser receives these resources, processes them, and displays the website on the screen. This process is called the request-response cycle. A static website displays fixed content that generally remains the same for every user until its files are changed, whereas a dynamic website generates or updates content according to user input, database information, or other conditions. Thus, the browser, client, server, and database work together to make websites accessible and functional.


Key Differences Between Static and Dynamic Websites


 *Static Website* 

• Displays fixed content.
• Usually uses HTML and CSS.
• Generally does not require a database.
• Example: A simple personal portfolio page.


 *Dynamic website*

•  Content can change according to user input or data.
• May use HTML, CSS, JavaScript, and server-side technologies.
• Often uses a database to store and retrieve information.
• Example: An online shopping website.
